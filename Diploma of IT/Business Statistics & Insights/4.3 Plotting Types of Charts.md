### Bubble Chart

 - This is used when you want to plot a y variable and 2 x variables. (Multiple linear regression).
 - For instance, in a scatter plot if you want to plot an additional variable like size then you can use a bubble chart
 - This is not needed for the #wsta1250/presentation.

### Sunburst chart
![[Pasted image 20260819140050.png|252]]
- ==this is needed for the #wsta1250 assignment==
- Provides a hierarchical view of the data
- Makes it easier to spot patterns.
- Only has 3 levels (so for example:)
	1. Region
	2. Category
	3. Sales
1. Bottom level is **always** a numerical variable (doesn't matter if it's discrete or continuous)
2. Can have multiple layers

### Treemap Chart

![[Pasted image 20260819135943.png|344]]
- Also a hierarchical chart. 
- Used to represent the sub-proportions of different categories
- The bottom layers are the numerical variable, and in this case the bottom three layers are a numerical variable (price, quantity and profit).


### Waterfall chart
![[Pasted image 20260819140700.png|298]]
 - This is another chart in the #wsta1250/presentation 
 - The waterfall chart shows a running total as values are added or subtracted from the starting point.
 - Useful for understanding how a value is affected in a positive or negative way over time, for instance account balance change over time.
