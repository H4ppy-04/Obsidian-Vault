When looking at whether you should apply a paired t-test or a two sample t-test, look at the number of populations.

You can also check if it uses 'before' and 'after' terms in which case you use paired t-test.

Meaning for each hypothesis:

1. $H_0: \mu_d = 0$  There is no significant difference between the two measurements taken.
2. $H_a: \mu_d \neq 0$ There is a significant difference between the two measurements taken.

#### Paired t-test

start with 1 population

- Take in one sample taken from population
- For each observation in the sample, take two measurements. (paired measurement)
- We test if the difference between the two measurements is equal to zero, in which case there is no significant difference so we fail to reject $H_0$.

#### Two-sample t-test

- Start with two separate populations
- Take one sample from each population.
- We only take one measurement of each sample which is the sample means.

#### Chi-squared test (will be in final exam)

- There is only one categorical variable
- All the categories should always equal to 100% or aka equal to 1.
- Given the sample size (often)

What the test is used for:

1. Determining how different things are allocated under each category.

2. For instance obese vs overweight vs normal weight
3. Or: Employed percent vs unemployed.

4. When comparing the difference between each category

Not all proportions are as stated in the null hypothesis.

$H_0: p_{dog}=59,p_{cat}=30,p_{other}=11$

$H_1:$ not all the proportions are as stated in the null hypothesis.

An observed value is actual count for each category based on the sample that is being taken.

Getting the expected values:

 $n$ $\times$ expected proportion listed in the null hypothesis

For instance $59 * 100\%$ is just 59.

The only assumption for a chi^2 test is that all expected values are equal to or larger than 5.

$$\chi^2=\sum_i\frac{(O_i-E_i)^2}{E_i}$$

And where:

- $\chi^2$ is just chi-squared
- $O_i$= observed value for group $i$
- $E_i$ = expected value for group $i$

This is only to calculate the chi-squared value of one category. Look at the number of categories and run this for each.

The degrees of freedom for the chi-squared test is the number of categories - 1.
