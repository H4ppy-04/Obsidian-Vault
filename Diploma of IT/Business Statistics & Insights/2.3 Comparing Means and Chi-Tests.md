### Equal Spread Assumption

To establish if $\sigma_1=\sigma_2$ to observe if ratio falls from $0.5..2$ That is, **neither sample deviation is more than twice the other.** (This is often inferred by comparing the IQR of a comparative box plot).

>[!quote]
>As long as the larger IQR $\lt$ (smaller IQR $\times 2$) then the equal spread assumption is satisfied.

### Paired $t$-test

 - There is only one population, from which we also only take one sample (as per usual).

To calculate this test we need:
$\bar{y}_D$
$s$
$n$

However you don't need to know how to calculate this.


The null and alternative hypotheses follow the same idea as other tests:
$H_0:\mu=0$
$H_a:\mu\neq 0$ 


##### Sample Data

| ... | Class Test 1 | Class Test 2 | Difference |
| --- | ------------ | ------------ | ---------- |
| R   | 100          | 80           | -20        |
| T   | 98           | 98           | 0          |
| G   | 50           | 100          | 50         |
| A   | 51           | 51           | 0          |
| R   | 80           | 80           | 0          |
For every observation in the sample we take two measurements. Class test 1 is our measurement one and class test 2 is our measurement 2.

In every case, we pair the two measurements together. This is where the name comes from.
We are always interested in the difference between the two measurements.


So calculate if the average difference is equal to zero or not.
The notation is $\mu_D=0$ where $D$ is just the difference.
Otherwise we can say $\mu_D\neq0$ 

==in the class test all the paired-t test questions have a before-after type question==


Typical usages for this test:
 - before and after
 - the difference in two sample groups where $\sigma$ is unknown.

You check that the graph of the differences is normal (that's an assumption that is made.)
