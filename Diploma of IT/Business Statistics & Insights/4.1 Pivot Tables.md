**Pivot table:** A powerful tool to analyze data.

- When doing the assignment, don't worry about the **filter box**.
- When having a categorical value, it either goes in the columns box or the rows box.

To create a pivot table: `Select any cell in the table` > `insert` > `pivot table`


How to change the value field settings:
![[Pasted image 20260817140813.png]]

In the assessment all values must be rounded to **3 decimal places**. `format cells` -> `decimal places`.

>You don't have to use the filter box in the assignment.
