- `xlookup` is more significant than other lookup functions.
	- It can handle `not found` cases
	- `xlookup` handles both *vertical* and *horizontal* lookups.
- Page number $13$ on the first document resource looks at the `countif` function. 
- `countif` *counts the number of cells that meets a specific criteria*.
	- For example, `countif(range, criteria)` where `criteria` can be an integer, floating point value, string, Boolean, etc. With the `criteria` it can also be a cell value, which acts the same as any other function as if you were filling out a function parameter with a cell.
- `vlookup` parameters: ✅
	- `lookup_value`: the value to look for
	- `array`: everything that is to the **right** of the column. (Rows and columns).
	- `col_index_num`: the index of the column with respect to the `lookup_value`
- Example of `vlookup`: `=VLOOKUP(B3,B2:E7,2,FALSE)`
