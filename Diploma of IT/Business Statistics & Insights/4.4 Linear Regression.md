## Intervals and Estimates

**Point estimate:** A single numerical estimate.

**Interval estimate:** A range of values used to estimate a population parameter. An interval estimate gives a greater chance of containing the true population parameter than a single point estimate.

### Confidence Intervals

- **Wider intervals** give **more confidence** that the interval contains the population parameter.
    
- **Narrower intervals** are **more informative/precise**, but are less likely to contain the population parameter.
    
- A **95% confidence interval** is a commonly used confidence level. It does **not** mean that there is a 95% probability that the specific interval contains the parameter.
    
- In general:
    
    - **Larger interval → more likely to contain the parameter, less informative**
    - **Smaller interval → less likely to contain the parameter, more informative**

# Simple Linear Regression

Simple linear regression is used to investigate the **linear relationship between two numerical variables**.

### Choosing the appropriate hypothesis test

|Variables|Appropriate test|
|---|---|
|One numerical variable|One-sample t-test|
|One numerical variable measured twice / paired observations|Paired t-test|
|One numerical + one categorical variable|Two-sample t-test|
|One categorical variable|χ² test|
|Two numerical variables|**Simple linear regression**|

### When to use simple linear regression

Use simple linear regression when you have **two numerical variables** and want to determine whether they have a linear relationship.

Examples:

- **x:** years of education → **y:** annual income
- **x:** height → **y:** weight
- **x:** hours studied → **y:** final exam result

**Important:** In simple linear regression, we model the effect/relationship of **x on y**. We do not interpret it as y affecting x.

### Terms for x and y

These do not need to be memorised:

|x|y|
|---|---|
|Predictor|Response|
|Determinant|Outcome|
|Independent|Dependent|

# Line of Best Fit

The **line of best fit** is the straight line that represents the trend between two numerical variables in a scatter plot.

More technically, it is the line for which the **sum of squared residuals is as small as possible**.

The regression equation is:

$$
\hat{y}=b_0+b_1x  
$$

Where:

- $(\hat{y})$ = **predicted/estimated value** of (y)
    
- $(b_1)$ = **slope**
    
- $(b_0)$ = **intercept (constant)**
    

**Memorize this equation.**

### Population regression line

$$
Y=\beta_0+\beta_1x  
$$

Here:

- $(\beta_0)$ = population intercept
    
- $(\beta_1)$ = population slope

# Least Squares Regression Line

The **least squares regression line** is the line that minimises the sum of squared residuals.

Its equation is:


$$\hat{y}=b_0+b_1x  $$


For example:


$$\hat{y}=3x+4.5  $$

This means:


$$\hat{y}=3(x)+4.5  $$

### Interpreting the slope

> **For every one-unit increase in the predictor variable (x), we expect the response variable (y) to change by (b_1) units, on average.**

- If$ (b_1>0), (y)$ **increases** as (x) increases.
    
- If $(b_1<0), (y)$ **decreases** as (x) increases.
    
- If $(b_1=0)$, there is **no linear relationship** between (x) and (y).
    

### Example

Suppose:

$$\hat{y}=22.01-1.31x  $$

where (x) is the age of a used Toyota Corolla and (y) is its price in **thousands of dollars**.

Interpretation:

> For every additional year in the age of a used Toyota Corolla, we expect its price to **decrease by an average of $1,310**.

**Always check the units of measurement.**  
Because the price is measured in thousands of dollars, a slope of (-1.31) means (-$1,310), not (-$1.31).

# Residuals

A **residual** is the difference between the **observed value** and the **predicted value**.

[  
\text{Residual}=y-\hat{y}  
]

For example:

- Predicted weight = 60 kg
    
- Actual weight = 70 kg
    
- Residual = (70-60=10) kg
    

**Note:** Residuals are not assessed on the final exam and do not need to be memorised.

# Linearity and Regression Notation

If there is **no linear relationship** between (x) and (y), then:

[  
\beta_1=0  
]

and the estimated slope will be:

[  
b_1\approx0  
]

When commenting on a linear relationship, you only need to establish whether the relationship is:

- **Positive**
    
- **Negative**
    
- **No linear relationship**
