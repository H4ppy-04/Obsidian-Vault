### Key Terms

| Definition            | Explanation                                                                                                                                                                                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Target Population     | A well defined group that comprises all relevant subjects of interest.                                                                                                                                    |
| Representative sample | A ==random== sample that shares similar characteristics with the ==target population==. It should be sufficiently large to give accurate information.                                                     |
| Random sample         | A sample where each member of the ==target population== has an equal chance to be selected.                                                                                                               |
| Variable              | A variable is a measurement that is taken from any study that is conducted. Examples may include gender, age or income.                                                                                   |
| Experimental Study    | A study where the investigator has some level of control over the ==intervention==.                                                                                                                       |
| Observational Study   | A study where there is **no intervention** by the investigator, *nor* is there any treatment imposed. Examples would be something where you don't have the ability to change any factor during the study. |
### Types of Variables

| Categorical Variables | Description                                                                                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Nominal variables     | Categorical variables with no inherent ordering: e.g. favorite share on the stock market. This assumes there are no conditions added.                                   |
| Ordinal variables     | Ordinal variables are categorical variables with some ordering: eg. Income group i.e. <50K, 50-100K, >100K.                                                             |
| Binary variables      | A categorical variable that only has **two categories**. It can be both ==nominal== *or* ==ordinal==. For instance you can have a categorical nominal binary variable.  |

| Numerical Variable | Description - Not a category but rather an actual single variable.                                                                                       |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Discrete           | Variable that take discrete value. e.g. number of students in class, number of shares owned. Deals with ==counting things==. These are ==integer only==. |
| Continuous         | Continuous variable are those that can assume any value, usually within a certain range. e.g. ==age== (years), weight (kg), income ($).                  |
