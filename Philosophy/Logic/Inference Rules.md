
## Modus Tollens (denying the consequent)

P -> Q
¬Q
∴ ¬P

### Example

**P** = It is raining
**Q** = It is wet

If it is wet then it is raining
it is not raining
therefore it is not wet

## Modus Ponens

Modus ponens is the most common inference rule, because it is the most simple and parsimonious. 

P -> Q
P
∴ Q

### Example

**P** = It is raining
**Q** = It is wet

If **it is wet** then **it is raining**
**it is raining**
therefore **it is wet**

## Affirming the Consequent (==invalid==)

The little brother of *modus tollens*. This is an invalid logical structure wherein the conclusion isn't necessarily guaranteed by the validity of the premises. 

I hope it is clear why, given the following logical structure.

P -> Q
Q
∴ P

### Example

**P** = It is raining
**Q** = It is wet

If **it is wet** then **it is raining**
**it is wet**
therefore **it is raining**

-> It's invalid because there could be other reasons as to why it is wet, not just that it is raining. For instance, someone could have used a hose, or a water tank may have leaked.
